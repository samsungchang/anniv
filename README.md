# 우리 기념일 — 아이폰 홈 화면 앱

## 들어 있는 파일
| 파일 | 역할 |
|---|---|
| index.html | 화면 |
| app.js | 기능 (계산, 사진, 꾸미기, 백업, 캘린더 내보내기) |
| sw.js | 오프라인에서도 열리게 하는 캐시 |
| manifest.webmanifest, icon-*.png | 앱 이름과 아이콘 |

사진과 기념일 데이터는 **아이폰 안에만** 저장돼요. 서버에는 올라가지 않아요.

## 배포 (GitHub Pages, 무료, 약 10분)
1. github.com에 로그인 → 오른쪽 위 **+ → New repository**
   - 이름: `anniv` / **Public** 선택 → Create repository
   - 무료 Pages는 Public 저장소가 필요해요. 올라가는 건 코드뿐이고, 사진은 올라가지 않아요.
2. 저장소 화면에서 **uploading an existing file** 클릭 → 이 폴더의 파일 7개를 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → **Save**
4. 1~2분 기다린 뒤 `https://<내아이디>.github.io/anniv/` 가 열리는지 확인

## 아이폰에 설치
1. **Safari**로 위 주소 열기 (크롬은 안 돼요)
2. 공유 버튼 → **홈 화면에 추가** → ("웹 앱으로 열기" 옵션이 보이면 켜기) → 추가
3. 홈 화면의 하트 아이콘으로 실행 → **꾸미기** 탭에서 이름, 사귄 날, 생일, 커버 사진 설정
   - 홈 화면 앱과 Safari는 저장 공간이 따로예요. 설정은 꼭 **아이콘으로 연 앱 안에서** 해 주세요.

## 알림 받기
기념일 탭 → **캘린더 파일 만들기** → 공유 시트에서 캘린더로 열기 → **모두 추가**
꼭 챙길 날마다 7일 전·하루 전 오전 9시에 아이폰 캘린더 알림이 와요.
기념일을 추가하거나 날짜를 바꿨다면 다시 만들어서 추가해 주세요. 이전 일정은 캘린더에서 지우면 돼요.

## 백업
꾸미기 탭 → **백업 저장** → 파일 앱이나 iCloud Drive에 저장
폰을 바꾸거나 앱을 지운 뒤에는 **백업 불러오기**로 복원해요. 한 달에 한 번 정도 백업해 두세요.

## 수정 후 업데이트
파일을 고쳐서 다시 올릴 때는 `sw.js` 첫 줄의 `VERSION` 값(`anniv-v1` → `anniv-v2`)을 바꿔 주세요.
앱을 한 번 닫았다 열면 새 버전이 적용돼요.
